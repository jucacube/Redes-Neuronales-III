# R1-A3-S7 Redes Neuronales III

Práctica de Deep Learning (Especialización en Inteligencia Artificial) con **TensorFlow + Keras** sobre MNIST.

## Contenido
- `Redes_Neuronales_III.ipynb`: notebook de Google Colab con todo el desarrollo.
- `figuras/`: gráficas generadas por el notebook.
- `resultados/`: tablas en CSV con los resultados de los experimentos.
- `Informe_Redes_Neuronales_III.pdf`: informe de entrega.

## Qué incluye
1. Distribución y preprocesamiento de datos (train / dev / test, normalización, estratificación).
2. Optimización: SGD, SGD con momentum, RMSprop y Adam con distintos learning rates.
3. Regularización: L1, L2, Dropout y Early Stopping.
4. Análisis de bias, variance y tradeoff.
5. Métricas: Accuracy, Precision, Recall, F1 y matriz de confusión.

## Cómo ejecutarlo
1. Abrir el notebook en Google Colab.
2. *Entorno de ejecución > Ejecutar todo*.
3. Se generan las carpetas `figuras/` y `resultados/` y el PDF del informe.
